# MIVIM.spec.vigiles

The active repository workflow is **[vigiles-vandal_0.2](vigiles-vandal_0.2.md)**.
Its name is **vandal**, and its workflow version is **0.2**. It operates only this
MIVIM Bamboozle repository. Read that specification and the repository-local
[skill](../.vigiles/skills/vigiles-vandal/SKILL.md) before continuing development.

Bamboozle is the product: reversible semantic translation, encoder/cipher APIs,
structured project views, and separate authenticated encryption/decryption.
Vandal is its proprietary agent operating workflow, with distinct agent and
operator contexts. Product version numbers do not set the workflow version.

The prior specification is preserved byte-for-byte as
[vigiles-vanilla_0.1](vigiles/specs/vigiles-vanilla_0.1.md), including its historical
implementation contracts. It supplies retained evidence and design history; it
does not override current user direction or the Vandal workflow.

[VIGILES_STATUS.json](../VIGILES_STATUS.json) remains the active development plan.
[Evidence storage](vigiles/reports/README.md) remains under `.mivim/vigiles/reports/`;
changing the workflow name does not relocate or discard existing records.
